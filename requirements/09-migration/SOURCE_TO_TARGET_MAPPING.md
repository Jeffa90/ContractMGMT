# Source-to-Target Mapping Specification

Mapping profiles are versioned and reusable per source system/version. Each field mapping supports source column, target core/custom field, transformation type, default, lookup mapping, requiredness, validation and notes.

Safe transformations include trim, case normalisation, date parse, decimal parse, boolean mapping, concatenation, split, fixed default and lookup mapping. No arbitrary code.

Provide preview of original and transformed values and count affected rows before commitment.
