# Cutover and Reconciliation

Migration projects record extraction dates, freeze windows, mock cycles, final load, owner acceptance and reconciliation evidence.

Reconcile:
- Source row count
- Records accepted/rejected/skipped/updated/created
- Source files and attachment manifest rows
- Files matched/unmatched/invalid/duplicate/imported
- Financial totals where meaningful
- Status and category distributions
- Sample record/document checks

No batch is complete until totals balance or documented exceptions are approved.
